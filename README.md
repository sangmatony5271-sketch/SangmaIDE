## ⚙️ গিটহাবে রিলিজ স্বয়ংক্রিয় করার জন্য ১টি জরুরি সেটিংস (GitHub Permission):

গিটহাবে স্বয়ংক্রিয় রিলিজ তৈরি হতে দেওয়ার জন্য আপনার রিপোজিটরিতে এটি সক্রিয় করুন:
1. আপনার GitHub রিপোজিটরির **Settings** ট্যাবে যান।
2. বাঁপাশের মেনু থেকে **Actions** -> **General**-এ ক্লিক করুন।
3. নিচে স্ক্রোল করে **Workflow permissions** সেকশনে যান।
4. **"Read and write permissions"** অপশনটি নির্বাচন করুন এবং **Save** বাটনে ক্লিক করুন।
*(এটি করলে প্রতিটি পুশে গিটহাব স্বয়ংক্রিয়ভাবে সরাসরি ডাউনলোডযোগ্য APK রিলিজ তৈরি করবে।)*

## 📱 কীভাবে মোবাইলে এপিকে ডাউনলোড ও ইনস্টল করবেন?

1. উপরের **[Download `app-debug.apk`](https://github.com/jsjuliussangma/NoTrack-IDE/releases/latest/download/app-debug.apk)** লিংকে ক্লিক করুন।
2. আপনার ফোনের ব্রাউজারে ফাইলটি সেভ করতে **Download anyway** বা **Save** সিলেক্ট করুন।
3. ডাউনলোড সম্পন্ন হলে ফাইলটির ওপর ট্যাপ করে **Install** বাটনে চাপুন (যদি "Install unknown apps" পারমিশন চায়, ব্রাউজারকে পারমিশন দিন)।
4. অ্যাপটি সফলভাবে চালু হবে!

## 🛠️ বিল্ড সিস্টেম (Build Features)

- **লোকাল গ্রেডল ইঞ্জিন (Gradle 8.7)**: লোকাল ডিভাইস কম্পাইলার
- **GitHub Actions অটোমেটিক CI/CD**: প্রতিটি কোড পুশে স্বয়ংক্রিয় এপিকে জেনারেশন
- **এন্ড-টু-এন্ড এনক্রিপশন (E2EE)**: সর্বোচ্চ নিরাপত্তা ও জিরো টেলিমেট্রি
